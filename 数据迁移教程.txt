Afterhours 1.0 → 2.0.2 数据迁移教程
====================================

适用范围
--------
本教程适用于已经使用过 Afterhours 1.0，并希望把历史记录带到 2.0.2 的用户。
没有 1.0 数据的用户可以直接解压并启动 2.0.2。

可以迁移的文件
--------------
activity.json    每天、每款游戏的前台与运行时长（需要迁移）
games.json       手动添加的游戏进程规则（需要迁移）
preferences.json 主题与深色模式设置（可选迁移）

不要迁移的文件
--------------
runtime.json、任何 .bak 文件、startup-error.log 和 error.log。

注意：1.0 没有保存每次游戏的具体开始和结束时间。旧数据可以继续显示在总时长、
分游戏统计和每日热力图中，但“最近记录”时间轴只能从 2.0.2 开始生成。

迁移前准备
----------
1. 在 1.0 和 2.0.2 中都点击关闭，并在系统托盘确认 Afterhours 已退出。
2. 找到 1.0 文件夹中的 data 文件夹。
3. 复制整个 data 文件夹作为备份，例如改名为 data-1.0-backup。
4. 完整解压 Afterhours-2.0.2.zip，先不要启动新版。

迁移步骤
--------
1. 在解压后的 Afterhours-2.0.2 文件夹中新建 data 文件夹。
2. 从 1.0 的 data 文件夹复制以下文件到新版 data：
   activity.json
   games.json
   preferences.json（如果存在）
3. 不要复制 runtime.json、任何 .bak 文件或日志。
4. 双击 Afterhours启动.vbs；如果启动失败，再运行 诊断启动.cmd 查看错误。

2.0.2 会自动忽略 1.0 games.json 中已经内置的规则和旧 Steam 自动规则，
只保留需要继续使用的手动规则，不需要手工清理该文件。

迁移后检查
----------
1. 首页历史热力图仍能看到旧日期记录。
2. “统计”中的总时长和游戏占比包含旧记录。
3. 设置中的手动游戏仍然存在。
4. 新游玩一次后，“最近记录”开始出现 2.0.2 的会话时间。

如果历史没有显示，请立即退出新版，不要反复启动或覆盖文件。先恢复之前备份的
data 文件夹，再检查复制的文件名是否正确、JSON 文件是否为空或损坏。

已经同时使用过两个版本
------------------------
如果 1.0 和 2.0.2 都已经产生了新记录，不要用一边的 activity.json 直接覆盖
另一边，否则会丢失其中一边的数据。请分别备份两个 data 文件夹后再合并；
sessions.json 只来自 2.0.2，也不要删除或覆盖。

从 2.0 更新到 2.0.2
--------------------
从托盘退出 2.0，备份整个 data 文件夹，然后把旧版的 activity.json、games.json、
preferences.json 和 sessions.json 复制到 2.0.2 的 data 文件夹。
不要复制 runtime.json、错误日志或 .bak 文件。
